# 03 开发步骤清单

按里程碑逐项完成，每步都有「做了什么」与「怎么验证」。建议每完成一步提交一次 Git（当前在 `feature/snake` 分支）。

## Step 0 环境与项目设置

- [ ] 用 VS Code 打开项目，确认 Godot 4.7 可正常打开（`project.godot` 版本为 4.7）
- [ ] 建议在项目设置里把「主场景」设为稍后创建的 `res://scenes/Main.tscn`
- [ ] （可选）在「项目设置 → Input Map」新增自定义动作：`move_up / move_down / move_left / move_right`，分别映射 `W/A/S/D` 与方向键，便于代码统一处理
- [ ] 运行 `godot` 可打开一个空场景的空窗口即成功

## Step 1 搭场景骨架

- [ ] 创建 `scenes/Main.tscn`，根节点为 `Node2D`（命名 `Main`）
- [ ] 添加子节点 `Game(Node2D)`、`Game/Snake(Node2D)`、`Game/Food(Node2D)`、`Game/MoveTimer(Timer)`（autostart 关、one_shot 关）
- [ ] 添加 `HUD(CanvasLayer)`，内含 `ScoreLabel`、`BestLabel`、`CenterMessage` 三个 `Label`
- [ ] 给场景挂脚本：`scripts/game.gd`、`scripts/snake.gd`、`scripts/food.gd`、`scripts/hud.gd`
- [ ] 验证：运行后场景能加载、无脚本报错

## Step 2 场地与坐标

- [ ] 在 `game.gd` 顶部定义 `GRID_W / GRID_H / CELL` 常量与 `grid_to_pixel()` 工具函数
- [ ] 绘制场地背景：用一个 `ColorRect` 或 `Polygon2D` 表示网格区域，方便看清边界
- [ ] （可选）画网格线：在 `Game` 上用 `_draw()` 按 `CELL` 间距画线，视觉更直观
- [ ] 验证：运行后能看到一个明显有边界的方格区域

## Step 3 让蛇动起来

- [ ] 在 `snake.gd` 里初始化身体（如 3 段：`[Vector2i(3,3), Vector2i(2,3), Vector2i(1,3)]`，头朝右）
- [ ] 实现 `request_turn()`（记录方向、禁止掉头）与 `step()`（头进尾出）
- [ ] 写同步显示的简单版：每段放一个色块节点，`step()` 后更新位置
- [ ] 连接 `MoveTimer.timeout → snake.step()`
- [ ] 输入：`_unhandled_input()` 里把 `ui_up/down/left/right`（或自定义动作）转成 `request_turn()`
- [ ] 验证：按方向键能转向；快速连按两个键不会 180° 自杀

## Step 4 边界与自身碰撞

- [ ] 在 `step()` 后判定新蛇头是否越界 → 发射 `game_over`
- [ ] 判定是否撞到自身（排除旧尾段的安全情况）
- [ ] `Game` 监听 `game_over` 信号，切换到结束状态并在中央提示文字
- [ ] 验证：故意撞墙、绕圈咬到自己都能正确结束并提示

## Step 5 食物、增长与计分

- [ ] `Game` 持有 `food_cell`，用 `spawn_food()` 在空格随机生成
- [ ] 蛇头与食物同格时：发 `food_eaten` 信号 → 身体增长（该拍不掉尾）+ 加分 + 重新 `spawn_food()`
- [ ] `HUD` 监听分数变化刷新 `ScoreLabel`
- [ ] 验证：吃一个食物长度 +1、分数 +1，食物每次刷新不压在蛇身上

## Step 6 流程完善

- [ ] 状态机 `READY / RUNNING / PAUSED / OVER` 在 `game.gd` 落地
- [ ] READY：显示「按方向键开始」，首次按键启动节拍器
- [ ] PAUSED：按 `P` 暂停/继续（`MoveTimer.stop/start`）
- [ ] OVER：显示「游戏结束，按 R 重开」，`R` 复位蛇与分数
- [ ] 分数上限时提示胜利（蛇填满全场）
- [ ] 验证：完整跑完「开始 → 吃 → 撞 → 重开」闭环无报错

## Step 7 打磨与扩展

- [ ] 速度递增：每吃一个缩短 `MoveTimer.wait_time`（设下限）
- [ ] 最高分：`user://best.txt` 读写，OVER 时更新显示
- [ ] 音效：吃食物 / 死亡（可用简单合成音或引擎 `AudioStreamGenerator` 占位）
- [ ] 造型：确认 `snake.png` 内容后决定蛇头/身体贴图方案，区分头尾
- [ ] 调参：网格大小、`CELL`、初始速度、加速幅度按手感调整
- [ ] 提交 `git flow feature finish snake` 前整理代码与注释

## 可选的后续扩展方向

- 穿墙模式（左右 / 上下互通）
- 障碍物与关卡
- 多种食物与道具（加速、减速、加分、反向）
- 头尾动画与平滑插值移动
- 触屏滑动 / 虚拟摇杆支持移动端
- 双人对战（各自一条蛇抢食物）
