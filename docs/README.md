# 贪吃蛇（gluttonous-snake）开发文档

基于 **Godot 4.7 + GDScript** 的 2D 贪吃蛇小游戏。本文档是编码前的设计蓝图，用于指导后续开发。

## 项目现状

- 引擎：Godot 4.7（GDScript），渲染后端 `Forward Plus`（D3D12）
- 已存在资源：`icon.svg`、`Assets/snake.png`（128 × 128，带透明通道）
- 尚未创建任何 `.tscn` 场景或 `.gd` 脚本，属于从零开始
- 当前处于 `git flow` 的 `feature/snake` 分支

## 一句话总结思路

把游戏区域想象成一张「方格纸」，蛇只做两件事：**每过一小段时间朝当前方向前进一格，头部顶到食物就变长**。所有逻辑都用整数网格坐标计算，画面只是把这份坐标数据「画」出来。这样逻辑清晰、不易出 Bug，也方便扩展。
